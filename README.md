# Task Organizer – Productivity & Automation Project

This project is a simple command-line Task Organizer designed to help users plan and manage their daily activities.  
It allows users to add tasks, view all saved tasks, and mark tasks as completed.  
The project is created under the domain *Productivity & Automation* as part of the flipped classroom course.

### Problem Statement

In everyday life, students and working individuals often struggle to remember and manage multiple tasks.  
To address this, I created a basic Task Organizer that helps users keep track of their pending and completed work.

### Objectives 

- To create a simple digital tool that helps users organise daily activities.
- To apply basic Python programming concepts in a real-world scenario.
- To use modular design by separating the project into multiple files.
- To create a clean and structured project that follows the guidelines in the course email.
