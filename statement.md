## PROJECT STATEMENT : MY TASK ORGANIZER 

### OVERVIEW 
The Task Organizer is a simple and user-friendly project created as part of the Problem Solving and Programming Lab. It helps users add, view, and manage daily tasks efficiently. The goal of this project is to develop logical thinking and programming skills by implementing basic operations such as input handling, looping, and conditional statements.

### PROBLEM STATEMENT 

Managing day‑to‑day tasks can be difficult without a proper system. People often forget important activities because they lack an organized method to track their work. The objective of this project is to build a basic Task Organizer that allows users to:

Add tasks
View all tasks
Mark tasks as completed
Exit the program when finished

This project provides hands‑on experience in designing flowcharts and writing programs using basic programming constructs.

## PROJECT SCOPE 

The Task Organizer is a beginner‑level project and focuses on:

~ Understanding the flow of a program
~ Using lists to store data
~ Implementing menus for user interaction
~ Applying loops and conditions for task management

## LEARNING OUTCOMES 

By completing this project, the student will:

~ Strengthen logical thinking
~ Learn practical implementation of lists, loops, and conditionals
~ Understand how to design and implement simple applications
~ Improve documentation and coding practices
